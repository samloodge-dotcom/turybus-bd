# Proyecto Final - Base de Datos TURYBUS

## Infraestructura del Servidor (Fases 1 y 2)
- **Servidor:** Ubuntu 26.04.1 LTS (`srv-turybus`)
- **Gestor BD:** MySQL Server 8.4.13 (puerto `3306` abierto a la red)

## Carpetas por Fase
- `03_esquema_datos/` -> María (tablas, vistas, procedimientos e inserts)
- `04_seguridad_roles/` -> Caro (roles y los 4 perfiles de usuario)
- `05_respaldos/` -> Caro (scripts de backup y restauración)
- `06_optimizacion/` -> Karla (consultas antes/después de índices y monitoreo)
- `07_app_web/` -> Marlis (aplicación web TURYBUS)
- `08_pruebas/` -> Karla / Equipo (pruebas integrales y multiusuario)
